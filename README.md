# 오늘의 호빵

여러 사람이 호빵 캐릭터를 꾸며 공유 찜기에 올리는 3D 멀티플레이 모바일 게임.
삼립호빵 IMC 캠페인 '오늘의 호빵' 온라인 참여형 플랫폼을 실제 플레이 가능한 게임으로 구현한 것이다.

## 플레이

`index.html`을 브라우저로 열면 바로 플레이할 수 있다. 별도 빌드가 필요 없다.

## 규칙

- 호빵 꾸미기: 맛 5종 · 표정 4종 · 소품 6종 · 이름 · 한마디
- 찜기에 올리기 +1°C, 반쪽 나누기 +3°C
- 온도 마일스톤 30°C / 50°C / 80°C, 자정 카운트다운
- 내 호빵 초대 코드 HB-XXXX, '따뜻해요' 하트
- 3D 광장: 드래그로 360° 회전, 핀치 줌, 바닥 탭으로 캐릭터 이동

## 기술

- Three.js (3D 찜기 광장, OrbitControls)
- Supabase Realtime (ezer-choir 프로젝트, 채널 `hobbang-today`) — 연결이 안 되면 1인 모드로 동작
- 내 호빵은 localStorage에 저장
